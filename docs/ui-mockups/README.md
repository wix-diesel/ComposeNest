# ComposeNest UIモック

v1の要件・アーキテクチャに基づく、画面ごとのHTMLモックです。各HTMLをブラウザで直接開けます。ビルドやパッケージのインストールは不要です。`assets`を含むフォルダー全体で利用してください。

## 画面

| HTML | 内容・確認できる操作 |
| --- | --- |
| [instances.html](instances.html) | 環境一覧。カード／DataGrid切替、サービス・環境名の検索、状態での絞り込み、列の並び替え、確認時刻の更新 |
| [templates.html](templates.html) | PostgreSQL・Redisのテンプレート、再読込みの通知 |
| [instance-create.html](instance-create.html) | PostgreSQL新規作成。入力、保存方式選択、パスワード表示、設定確認 |
| [instance-detail.html](instance-detail.html) | 概要・ログ・Composeのタブ、秘密表示・コピー、起動／停止表示、再起動・削除確認 |
| [instance-clone.html](instance-clone.html) | 設定の複製。差分、用途名入力、保存方式、データ非複製の確認 |
| [instance-edit.html](instance-edit.html) | 停止中の環境の名前・ポート編集、変更確認 |
| [operation.html](operation.html) | 作成進捗、完了／失敗の表示切替、再試行の例 |
| [diagnostics.html](diagnostics.html) | Docker診断、接続不能の表示、再確認 |
| [retained.html](retained.html) | 削除後に保持するデータ、元の設定の所在 |
| [settings.html](settings.html) | 既定保存方式、管理ルート、認証情報の保存方針 |

ページ遷移はありません。ナビゲーションなどのボタンは通知だけを表示します。環境の操作状態はページ内だけで保持し、再読込みで初期状態に戻ります。コピー操作はブラウザの許可がある場合にサンプル値をクリップボードへコピーします。

## テーマ・一覧表示

- 設定ページの「デザイン」からライト／ダークを選べます。選択するとすぐに適用・保存され、各画面のフォーム・確認ダイアログ・ログ周辺にも反映されます。
- 環境一覧の「カード／DataGrid」で表示を切り替えます。検索・状態の絞り込みはそのまま引き継ぎます。
- DataGridでは環境名・状態・接続先の列見出しをクリックすると昇順／降順に並び替えます。行数が多い場合は表内をスクロールでき、見出しを固定しています。狭い画面では横スクロールできます。
- テーマと表示形式のみブラウザのlocalStorageに保存します。利用できない場合も、その画面内で切り替えられます。認証情報は保存しません。
- HTMLを直接開いた場合、保存範囲や他のHTMLとのテーマ共有はブラウザに依存します。同一のローカルHTTPサーバーから開く場合は、各画面・タブでテーマを共有します。

## 表示上の前提

- 日本語UI、ライト／ダークテーマ、デスクトップを主対象としたレイアウト。狭い幅ではカードやフォームを縦に並べます。
- 画面は表示検討用です。実際のDocker操作、ファイル操作、設定保存、空きポートの確認は実施しません。HTMLの必須・範囲チェックだけを行います。
- 実行状態・処理結果・構成一致を分けます。接続不能を停止中とは扱いません。
- 複製は設定のみ。削除時にデータを残し、ポート編集後も停止状態を維持します。
- パス・バージョン・日時・認証情報はすべてサンプルです。Windowsの管理ルートを表示例に使っています。
- PostgreSQL 18 / 17、Redis 8.2は既存のTemplate仕様例に基づきます。実機検証済みの配布対象を表すものではありません。
- Composeタブはマスキングと閲覧のUIを示す抜粋であり、生成Composeの実装・完全な契約ではありません。
- 2026-09-22のユーザー指定により、本体のReact/Tauri実装の見た目・画面構成・操作導線の基準とします。モックのサンプル値や疑似操作は本番仕様にせず、仕様書の安全条件を維持します。実装完了や実機検証済みを意味しません。

[画面別の実装タスク対応表](../ui-implementation-plan.md)に、各画面の担当Issue、サンプルと本番の差異、PRの分割方針をまとめています。

共通の見た目は`assets/styles.css`、基本操作は`assets/mock.js`、テーマと表示形式は`assets/appearance.css`・`assets/appearance.js`、DataGrid操作は`assets/instances-view.js`にまとめています。表の行はカードと同じサンプルデータから作成します。外部CDN・フォント・画像・通信への依存はありません。
