設定を複製

「開発用データベース」の設定から、独立した新しい環境を作成します。

設定だけを複製します。データは複製しません。

複製元のデータや稼働状態には影響しません。複製先は新しいデータ領域から始まります。

複製先の保存方式

複製元の方式を初期選択しています。方式を変えてもデータの移行は行いません。

確定時にポートの候補を再検証します。
